# 📱 ProyectoFinalTUDAI

Aplicación Android desarrollada en **Kotlin** como proyecto final académico, orientada a aplicar buenas prácticas de desarrollo móvil, organización de código y estructura de proyectos reales.

El objetivo principal del proyecto es consolidar conocimientos de desarrollo Android mediante una aplicación funcional, clara y mantenible.


## 🚀 Tecnologías utilizadas

* **Kotlin**
* **Android SDK**
* **Gradle (Kotlin DSL)**
* **Android Studio**

*(Según el proyecto: puede incluir Room, ViewModel, LiveData, etc.)*


## ✨ Funcionalidades principales

* Interfaz móvil desarrollada en Android
* Navegación entre pantallas
* Gestión de datos internos (según el alcance del proyecto)
* Arquitectura organizada para facilitar mantenimiento y escalabilidad
* Separación de responsabilidades entre lógica y presentación

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/fabrilea/ProyectoFinalTUDAI.git
   ```

2. Abrir el proyecto con **Android Studio**.

3. Esperar a que Gradle sincronice dependencias.

4. Ejecutar en un emulador o dispositivo físico Android.


## ⚙️ Requisitos

* Android Studio (versión actual)
* SDK Android instalado
* Emulador o dispositivo físico
